# Контекст языковой модели

Контекстное окно — ограниченный объём токенов входа и выхода модели. В него входят системная инструкция, текущий запрос, история и результаты инструментов. Историю ограничивают по числу сообщений и токенам, сохраняя полные пары вопрос/ответ.

Структурированный вывод ограничивает ответ JSON-схемой: имена полей, типы, обязательность и допустимые значения. Приложение повторно проверяет JSON. Валидная схема не гарантирует истинность фактов и не даёт права выполнять действие.
