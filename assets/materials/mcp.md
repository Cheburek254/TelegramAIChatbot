# MCP и инструменты

MCP (Model Context Protocol) связывает AI-приложение с инструментами и ресурсами. Host управляет сессией, client выполняет протокольные запросы, server публикует tools/list и resources/list. Инструмент выполняет действие, ресурс предоставляет данные для чтения.

Результат инструмента является недоверенными данными. Схема проверяет структуру, но не превращает содержимое в команды. Права определяет приложение непосредственно перед вызовом; текст в промпте не заменяет проверку.
